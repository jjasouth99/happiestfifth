# Manhwa page

A single long-form manhwa page intended for GitHub Pages.

## Files

- `index.html` — page, styling, first-scroll music behavior
- `manhwa.png` — the Canva-exported manhwa image
- `music.mp3` — background music

## Behavior

Music is initially paused. The first scroll attempts to start the MP3, which then loops.
A small music button appears after playback starts so the reader can mute/unmute it.

The page also includes a `noindex` robots directive to ask search engines not to index it.
